3. Власний метод розширення TotalStudents()
Створено статичний клас DepartmentExtensions із методом розширення для IEnumerable<Department>, який обчислює сумарну кількість студентів:

C#
public static class DepartmentExtensions
{
    public static int TotalStudents(this IEnumerable<Department> departments)
    {
        if (departments == null) return 0;
        return departments.Sum(d => d.NumStudents);
    }
}

Відповіді на контрольні питання
Для чого використовується оператор SelectMany? Відмінність від Select:

Select виконує проекцію «один до одного» і для вкладених списків повертає колекцію колекцій (IEnumerable<List<T>>).

SelectMany виконує проекцію «один до багатьох» і об'єднує (сплющує) усі вкладені колекції в одну єдину плоску послідовність (IEnumerable<T>).

Як реалізувати пагінацію даних за допомогою LINQ?

За допомогою комбінації методів Skip((pageNumber - 1) * pageSize) (пропускає елементи попередніх сторінок) та Take(pageSize) (бере задану кількість елементів для поточної сторінки).

Концепція методів розширення (Extension Methods) та інтеграція з LINQ:

Методи розширення дозволяють додавати нові методи до існуючих типів або інтерфейсів без зміни їхнього вихідного коду чи успадкування. Вони оголошуються як static методи у static класі, де перший параметр має модифікатор this. Увесь стандартний LINQ побудований як набір методів розширення для інтерфейсу IEnumerable<T>.

Приклад власного методу розширення для IEnumerable<T>:

Метод public static int TotalStudents(this IEnumerable<Department> departments) додає до будь-якої колекції кафедр можливість викликати .TotalStudents() у ланцюжку LINQ-запитів для підрахунку загальної кількості студентів.
