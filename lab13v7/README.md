# Лабораторна робота №13 (Варіант 7)
**Тема:** Generic-методи для повторного використання компонентів: Mapper/MaxBy/Reduce з Func/Action.

## Опис реалізованих методів у `FunctionalUtils`
1. **`Map<T, TResult>`**: Перетворює список елементів типу `T` у список елементів типу `TResult` за допомогою заданої функції `Func<T, TResult>`.
2. **`Filter<T>`**: Фільтрує список, залишаючи лише ті елементи, що відповідають умові `Func<T, bool>`.
3. **`Reduce<T, TAccumulate>`**: Згортає всі елементи списку до одного акумульованого значення за допомогою `Func<TAccumulate, T, TAccumulate>`.
4. **`Skip<T>`**: Пропускає перші `n` елементів списку та повертає решту.
5. **`Take<T>`**: Повертає лише перші `n` елементів списку.

Усі методи продемонстровано в `Program.cs` на трьох різних типах даних: `int`, `string` та власному класі `Department`.

## Відповіді на контрольні запитання

### 1. Що таке generic методи і які переваги вони дають?
Це методи, в описі яких використовуються параметри типів (наприклад, `<T>`).
- **Переваги:**
  - Повторне використання коду для різних типів даних.
  - Строга типізація під час компіляції (Type Safety).
  - Відсутність втрати продуктивності через пакування/розпакування (boxing/unboxing).

### 2. Яка різниця між делегатами Func<T> та Action<T>?
- **`Func<...>`**: Представляє метод, який **повертає значення**. Останній generic-параметр визначає тип повертаного значення (`Func<T, TResult>`).
- **`Action<...>`**: Представляє метод, який **нічого не повертає (`void`)** (`Action<T>`).

### 3. Що таке функції вищого порядку? Наведіть приклади.
Це функції, які можуть приймати інші функції як аргументи або повертати їх.
- **Приклади:** `Map` (приймає функцію трансформації), `Filter` (приймає предикат), `Reduce` (приймає функцію об'єднання), а також LINQ-методи `Select`, `Where`, `Aggregate`.

### 4. Навіщо потрібні обмеження (constraints) для generic типів?
Обмеження (`where T : ...`) вказують компілятору, якими властивостями або методами володіє параметр типу `T`. Це дозволяє безпечно викликати операції порівняння (`IComparable<T>`), створювати об'єкти (`new()`) або звертатися до методів певних інтерфейсів/класів.

### 5. Як лямбда-вирази спрощують роботу з делегатами?
Лямбда-вирази дозволяють створювати анонімні функції безпосередньо у місці їх виклику за допомогою лаконічного синтаксису `(x => x * x)` замість явного оголошення окремих методів або екземплярів делегатів.
