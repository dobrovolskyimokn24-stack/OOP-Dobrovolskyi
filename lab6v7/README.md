Звіт з Лабораторної роботи №6 (lab6v7)
Тема: Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
Варіант: №7

1. Опис реалізованої ієрархії класів

У роботі реалізовано ієрархію класів Person -> Student -> Professor.

Класи та їх структура:

Person (базовий клас):
Поля та властивості: Name, Age.
Віртуальний метод Greet: виводить привітання людини.
Звичайний метод GetRole: повертає рядок "Людина".

Student (похідний клас від Person):
Поля та властивості: StudentId.
Конструктор: викликає конструктор базового класу через base(name, age).
Перевизначений метод Greet: виводить привітання студента.
Власний метод Study: виводить інформацію про навчання.
Приховування члена GetRole (new): повертає рядок "Студент".

Professor (похідний клас від Person):
Поля та властивості: Department.
Конструктор: викликає конструктор базового класу через base(name, age).
Перевизначений метод Greet: виводить привітання викладача.
Власний метод Teach: виводить інформацію про проведення лекції.


2. Результати виконання програми

У програмі продемонстровано:
Поліморфізм (virtual та override): при виклику методу Greet через список List<Person> кожен об'єкт викликає свою власну перевизначену реалізацію.
Різницю між override та new:
Метод Greet (override) викликає реалізацію Student незалежно від типу посилання.
Метод GetRole (new) залежить від типу посилання: через змінну типу Student повертається "Студент", а через змінну типу Person повертається "Людина".


3. Відповіді на контрольні запитання

1. Принцип наслідування:
Дозволяє похідному класу успадковувати поля та методи базового класу за принципом "є різновидом". Наприклад, клас Транспортний засіб є базовим, а Автомобіль та Мотоцикл є похідними.

2. Ключове слово base:
Використовується для доступу до членів базового класу з похідного класу. Застосовується для виклику конструкторів базового класу або виклику базових методів.

3. Різниця між virtual та override:
Ключове слово virtual у базовому класі дає дозвіл на перевизначення методу, а override у похідному класі надає нову реалізацію. Це забезпечує динамічний поліморфізм під час виконання програми.

4. Модифікатор new:
Використовується для приховування методу базового класу, якщо ми не хочемо використовувати поліморфізм. При цьому виклик методу залежить від типу змінної-посилання, а не від типу створиного об'єкта.
